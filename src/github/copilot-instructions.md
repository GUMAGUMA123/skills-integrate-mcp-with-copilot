# Directrices de Revisión de Código con Copilot

## Seguridad
- Céntrese en la seguridad y evite la interpolación de cadenas no seguras.
- Revise si hay vulnerabilidades de inyección SQL, XSS u otros tipos de ataque.
- Valide todas las entradas externas antes de procesarlas.

## Documentación
- Asegúrese de que las funciones tienen docstrings que explican los parámetros y los tipos de valor devuelto.
- Verifique que el código esté bien documentado y sea comprensible.

## Otros puntos de revisión
- Busque errores de lógica o condiciones no manejadas.
- Sugiera mejoras de rendimiento y eficiencia.
- Valide el formato y estilo del código según los estándares del equipo.
